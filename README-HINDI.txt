RAJ PRODUCT IMAGE AUTO-MAPPING V8
=================================

1. Product images public\assets\products me copy karein.
2. Project root ka START_ADMIN.bat run karein.
3. Mapper product code aur full product name se image match karega.
4. Browser automatically open hoga.
5. Result project root ke PRODUCT_IMAGE_MAPPING_RESULT.txt me milega.

External image folder optional hai. Uska full path project root ke
PRODUCT_IMAGE_FOLDER.txt me ek nayi line par likh sakte hain.
