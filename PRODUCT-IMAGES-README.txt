PRODUCT IMAGE AUTO-MAPPING V8
=============================

Images yahan rakhein:
assets\products\

Recommended filenames:
- Product code: 00PAF8878.jpg
- Full product name: 00PAF8878-Air Filter Element.png
- Code + name: 00PLF5502 Lube Oil Filter.webp

Windows-invalid code example:
- Product code 4*09 ke liye 4x09.jpg ya 4-09.jpg use karein.

Supported: WEBP, PNG, JPG, JPEG, JFIF, AVIF, GIF, BMP, SVG

Project root ka START_ADMIN.bat run karein.
Map: data\product-image-map.json
Report: data\product-image-report.json
